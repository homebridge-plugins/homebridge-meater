Thank you for using homebridge-meater

Plugin Information
  • This plugin allows you to view your MEATER thermometer readings within HomeKit. The plugin:
    • requires your MEATER account credentials to work
    • connects to the MEATER Cloud REST API to retrieve probe temperatures
    • exposes internal and ambient temperature sensors for each probe, plus a Cook Refresh switch
Prerequisites
  • To use this plugin, you will need to already have:
    • Node: latest version of v22 or v24 - any other major version is not supported.
    • Homebridge: v2 - refer to link for more information and installation instructions.
